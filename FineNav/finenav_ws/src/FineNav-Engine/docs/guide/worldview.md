# Write a WorldView

A WorldView makes your selected Map usable by your selected Planner.
Implement the Planner's `IWorldView` interface using queries from the Map.

## Connect the queries

The example Planner expects `isWalkable(position)`. The example Map provides
`isOccupied(position)`, so the WorldView returns the opposite result.

Below is a reduced version of `SimpleWorldView`. It uses the parameter type
already generated by the example package:

```cpp
#include <rclcpp/rclcpp.hpp>
#include "dummy_map.hpp"
#include "dummy_planner.hpp"
#include "finenav_example/dummy_world_view_params.hpp"

namespace finenav::example {
class SimpleWorldView : public DummyPlanner::IWorldView {
public:
    using ConfigType = dummy_world_view::Params;

    SimpleWorldView(rclcpp::Node::SharedPtr, const DummyMap& map)
        : map_(map) {}

    void configure(const ConfigType&) {}
    void prepare(const core::PlanningContext<DummyPlanner>&) {}

    bool isWalkable(const common::Position3D& p) const override {
        return !map_.isOccupied(p);
    }

private:
    const DummyMap& map_;
};
}
```

Use `configure()` for your WorldView parameters. Use `prepare()` to derive
information needed for the next plan, such as costs around the robot.
It can be empty when direct Map queries are sufficient.

## Register and build it

Register the WorldView in its `.cpp` file:

```cpp
#include "dummy_world_view.hpp"
#include "finenav_core/algo_register_macros.hpp"

FINENAV_REGISTER_WORLDVIEW(
    finenav::example::SimpleWorldView,
    dummy_world_view,
    finenav::example::DummyPlanner,
    finenav::example::DummyMap)
```

The registration declares the selected Planner and Map types. The application
can then assemble them using the name `dummy_world_view`.

Start from the complete
[WorldView example](https://github.com/FineNav/FineNav-Engine/tree/81c8f277518fb9229eb5e78be43375227490ce39/finenav_example/create_custom_world_view),
including its YAML parameter schema and CMake configuration. For your own plugin,
rename the class and parameter namespace consistently, link the chosen component
libraries, and install the WorldView as a shared library.

Next, [configure your C++ application](cpp-application.md) to load it.
