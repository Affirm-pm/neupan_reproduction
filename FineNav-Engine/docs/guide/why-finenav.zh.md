# 为什么选择 FineNav-Engine？

FineNav-Engine 支持按需组装分层控制架构。选择符合框架接口的已有或自定义 Map 和 Planner，
编写连接两者的 WorldView，调用框架 API 构建导航系统。
框架还提供运行时控制分支切换机制，可通过行为树选择预先组装并注册的 pipeline。

## 1. 分层控制组装

每个控制层封装自己的算法与执行策略，通过明确的输入、输出接口与其他层连接。
各层算法实现解耦。在上下层输入、输出接口兼容的前提下，可按需配置层数、组合方式和执行频率，
将规划、跟踪等环节组装成适合机器人的控制 pipeline。

例如，入门示例将直线路径规划层与路径跟踪层连接起来：前者生成位姿路径，
后者根据路径持续输出速度指令。需要更换规划算法时，可以保留跟踪层，
接入输入、输出匹配的新规划层，复用其余流程。

[组装控制 Pipeline](cpp-application.md)。

## 2. 组件适配与集成

选用已适配框架的 Map、Planner，或按框架接口实现并注册自定义插件。
WorldView 将 Map 的数据查询适配为 Planner 需要的接口，让地图表示与规划算法能够独立选择和复用。

组件完成接口适配和插件注册后，应用侧主要需要编写所需的 WorldView 适配，调用框架 API 加载插件、创建控制层并连接分支，
再配置运行参数和任务行为。框架负责组件组装与执行。

例如，示例中的 Map 提供“是否被占据”的查询，Planner 需要“是否可通行”的判断。
WorldView 完成两者之间的转换后，应用通过注册名称选择该组合，无需在主程序中处理地图查询细节。

[编写 WorldView](worldview.md)。

## 3. 运行时分支切换

同一个导航系统可以预先组装并注册多条控制分支，在运行时通过行为树选择和切换当前执行的 pipeline。
不同分支可以采用不同的控制层组合，应用通过行为树中的任务逻辑决定何时选用哪条分支。

这为在同一套应用中组织多种导航策略提供了基础。具体分支组合及切换行为需结合应用验证，
尤其是多个分支共享控制层时的数据衔接与启停行为。

[配置行为树](behavior-tree.md)。
